    Features
    
          
    Built for the way you actually run agents.
    
          
    
            Some work can't run in the cloud: a Unity editor that takes minutes to warm up, a real GPU, a
            local toolchain. Claude Local makes a fleet of local sessions as easy to handle as a chat list.
          
    
        
    
        
    
          
    
            
    
              
            
    
            
    Every session at a glance
    
            
    
              Interactive and background sessions, grouped by project, with live busy/idle status. Filter by
              kind, project or name.
            
    
          
    
          
    
            
    
              
            
    
            
    Never idles out
    
            
    
              Background sessions idle after 8 hours with nothing attached. Claude Local quietly holds a hidden
              client on each one, so long-running work keeps running.
            
    
          
    
          
    
            
    
              
            
    
            
    Double-click to attach
    
            
    
              Opens claude attach in Terminal, iTerm2, Ghostty, WezTerm, kitty, Alacritty, Windows
              Terminal or your own command. Only installed terminals are offered.
            
    
          
    
          
    
            
    
              
            
    
            
    Start agents anywhere
    
            
    
              Pick a project folder, name it, write the first prompt. Launch it in the background or in a
              terminal. Recent folders are remembered.
            
    
          
    
          
    
            
    
              
            
    
            
    Deletes that ask twice
    
            
    
              Delete asks before it acts. If the session's worktree holds unpushed commits, you see Claude's own
              warning and must confirm a second time to discard them.
            
    
          
    
          
    
            
    
              
            
    
            
    Checks its own setup
    
            
    
              Missing claude, tmux or your terminal? It opens with a setup card,
              a copy-paste fix, and clears itself once you install it.
            
    
          
    
        
    
      
    

      
      
    
        
    
          
    How it works
    
          
    A small Rust core doing careful process work.
    
          
    
            The interface is a list. Behind it, the app polls Claude Code, keeps a hidden client attached to
            every background session, and works out how to open your terminal.
          
    
        
    

        
    
          
    
            Tray app
            Tauri 2 + Rust
            polls every 3 s while open, 30 s while hidden

    /// Start a client for every background session that lacks one, and stop
/// clients whose session has gone away.
pub fn reconcile(&mut self, env: &ToolEnv, sessions: &[Session]) -> Report {
    let wanted: HashMap<&str, &Session> = sessions
        .iter()
        .filter_map(|s| s.attach_id().map(|id| (id, s)))
        .collect();
    let running = self.backend.running()?;

    for id in running.iter().filter(|id| !wanted.contains_key(id.as_str())) {
        self.backend.stop(id)?;               // session is gone
    }
    for (&id, session) in &wanted {
        if running.contains(id) || self.recently_started(id) { continue; }
        self.backend.start(env, id, &session.cwd)?; // hidden `claude attach`
    }
    // …
}
    
        
    
      
    

      
      
    
        
    
          
    Engineering notes
    
          
    Small app. Sharp edges handled.
    
        
    
        
    
          
    
            
    Native, not Electron
    
            
    
              Tauri 2 uses the OS's own webview, so no browser ships inside the app. The whole UI is about
              15 KB of plain TypeScript with no framework; everything else is Rust.
            
    
          
    
          
    
            
    GUI apps can't see your PATH
    
            
    
              Apps launched from Finder get a bare /usr/bin:/bin. Claude Local asks your login shell
              for its real PATH once, with a timeout, so Homebrew's tmux and
              ~/.local/bin/claude just work.
            
    
          
    
          
    
            
    A private tmux server
    
            
    
              Keep-alives run on their own socket (tmux -L claude-local). They survive quitting or
              updating the app and never clutter your tmux ls. Windows uses ConPTY instead.
            
    
          
    
          
    
            
    Fails safe
    
            
    
              A failed session listing never triggers cleanup, so one hiccup can't tear down every keep-alive. A
              destructive delete only runs with the exact values Claude reported, held by the app rather than
              the page.
            
    
          
    
          
    
            
    Tested where it matters
    
            
    
              The Rust core has no UI and runs headless. Its tests drive a real tmux server and fake
              claude binaries. CI runs on macOS, Windows and Linux.
            
    
          
    
          
    
            
    One tag, two installers
    
            
    
              Pushing a v* tag builds a universal macOS .dmg and Windows installers on
              GitHub Actions and attaches them to a draft release.
